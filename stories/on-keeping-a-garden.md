# on keeping a garden

A website used to be a place you tended. You put things in it because you
liked them, not because they would perform.

This one is literally a folder. When I drop a file in, it appears. When I drag
an icon somewhere in Finder, the page moves to match. There is no CMS, no
dashboard, no draft state. There is a folder, and the folder is the site.

Write the next one in this folder as a `.md` file and it will show up here.
