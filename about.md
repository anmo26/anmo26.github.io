# anmo.garden

this is a file gallery. it is a mirror of the folder that hosts it.

every page here was written by `src/grow.js`, which walks the folder,
looks at each file, and reads the icon positions that Finder stores in
the invisible `.DS_Store` file sitting in each directory.

so the way things are scattered on this page is not a design decision
made in CSS. it is wherever i dragged the icons in a Finder window.

to rearrange the site, rearrange the folder.
